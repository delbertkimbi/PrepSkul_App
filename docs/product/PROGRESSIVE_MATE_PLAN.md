# Progressive learning with Mate

## Learning loop
1. Resume the learner's current objective using their class, curriculum and prior answers.
2. Teach one small idea with a short spoken explanation and an interactive visual when useful.
3. Ask the learner to predict, manipulate or answer before revealing the explanation.
4. Keep feedback visible until the learner chooses to continue. Show question position and explain mistakes.
5. After a mistake, offer a worked example and a fresh independent question. Never turn a revealed answer into mastery.
6. Unlock the next lesson only after validated independent success. Keep previous lessons available for review.
7. Save progress and resources for offline review; distinguish saved practice from live generation.

## Delivered in this pass
- Explicit question position, full-width answer choices and persistent feedback.
- Learner-controlled Next question / Finish practice actions.
- Continue or Review with Mate action after saving.
- Preserve incorrect results across a multi-question practice and retry failed saves.
- Phone checkout launcher and debug signing configuration fix.

## Remaining acceptance work
- Verify server mastery thresholds against curriculum-specific assessment sets, including multiple independent checks.
- Validate that generated questions match class, topic and exam style; label sourced exam material accurately.
- Add interactive teaching assets beyond quiz choices and verify spoken explanation synchronization.
- Regenerate older offline audio with the approved voice style; deploy the shared voice backend.
- End-to-end phone verification of review, correction, next lesson unlock and offline resume.
- Complete the broader classroom, messaging and booking consistency audit.

A saved answer is not by itself proof that a whole topic is mastered.
